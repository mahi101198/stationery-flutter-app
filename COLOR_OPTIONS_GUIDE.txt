COLOR OPTIONS IMPLEMENTATION (SIMPLE)
======================================

OVERVIEW
--------
Add a color selection dropdown to product details page.
User sees available colors and can select one.

DATABASE SETUP
--------------

Collection: product_details
Document ID: {same as productId}

Add ONE field:
- colors: ["Red", "Blue", "Green"] (array of strings)

EXAMPLE
-------

WITHOUT colors field (no color selector shown):
{
  "productId": "1zaaOVRcw81Yd1XhKmhb",
  "description": "ert",
  "images": [...],
  "miniInfo": [...],
  "tags": [],
  ...
}

WITH colors field (color selector shown):
{
  "productId": "1zaaOVRcw81Yd1XhKmhb",
  "description": "Premium quality pen",
  "images": [...],
  "miniInfo": [...],
  "tags": [],
  "colors": ["Red", "Blue", "Green", "Black"]  ← ADD THIS
  ...
}

HOW TO ADD IN FIRESTORE CONSOLE
--------------------------------

1. Go to Firestore Console → product_details collection
2. Click on your product document
3. Click "Add field"
4. Field name: colors
5. Field type: array
6. Add items:
   - Click "Add item"
   - Type: string
   - Value: "Red"
   - Click "Add item" again for more colors
7. Click "Update"

BEHAVIOR
--------
✅ If colors field exists and has items → Color selector appears
❌ If colors field is empty or missing → No color selector

The color selector appears between Price and Description sections.

SUPPORTED COLOR NAMES
----------------------
Red, Blue, Green, Yellow, Orange, Purple, Pink, Black, White, 
Grey/Gray, Brown, Cyan, Teal, Indigo, Lime

You can use any color name - these will show proper color circles.

THAT'S IT!
----------
No changes to products collection needed.
Just add colors array to product_details collection.
