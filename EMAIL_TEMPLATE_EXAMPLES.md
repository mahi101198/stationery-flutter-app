## 🎨 Design Features

### Color Scheme by Status
```
📝 Placed        → #3498db (Blue)
✅ Confirmed     → #667eea (Indigo)
📦 Packed        → #f39c12 (Orange)
🚚 Shipped       → #9b59b6 (Purple)
📍 Out Delivery  → #e74c3c (Red)
🎉 Delivered     → #27ae60 (Green)
❌ Cancelled     → #c0392b (Dark Red)
↩️ Returned      → #95a5a6 (Gray)
💰 Refunded      → #16a085 (Teal)
```

### Typography
- **Header Font**: Segoe UI, 28px, Bold, White on Gradient
- **Titles**: 16-20px, Bold, Dark Gray
- **Body Text**: 14px, Regular, Dark Gray
- **Labels**: 12px, Uppercase, Medium Gray

### Layout Elements
- Max Width: 600px (mobile responsive)
- Padding: 20-30px (comfortable spacing)
- Border Radius: 4-8px (modern appearance)
- Shadows: Subtle 2px shadows for depth
- Icons: Unicode emojis for universal support

### Mobile Responsive
- Single column layout on small screens
- Touch-friendly button sizes
- Readable font sizes
- Full-width on mobile devices

## 📊 HTML Template Sections

### Each Email Contains:
1. **Header** (Gradient background, status emoji, order ID)
2. **Status Box** (Large emoji, title, description)
3. **Info Grid** (Order ID, Total, Previous Status, Current Status)
4. **Items Table** (Product details, quantities, prices)
5. **Update Timestamp** (Local timezone)
6. **Footer** (Company branding, support info)

### Responsive Features
- ✅ Works in all email clients (Gmail, Outlook, Apple Mail, etc.)
- ✅ No external CSS dependencies
- ✅ Inline styles for maximum compatibility
- ✅ Fallback text for non-HTML clients
- ✅ Unicode emoji support
- ✅ Indian Rupee (₹) symbol support
