DETAILED FIELD DESCRIPTIONS
----------------------------

items (Array of Objects):
  - productId (string): Product ID from products collection
  - quantity (number): Quantity ordered
  - name (string): Product name
  - price (number): Current selling price (after discount)
  - productImage (string): Product image URL
  - discountPrice (number): Same as price (discount already applied)
  - selectedColor (string, OPTIONAL): Selected color if product has colors
    * Only included if user selected a color
    * Value comes from colors array in product_details collection

amountSummary (Object):
  - subTotal (number): Sum of all item prices
  - discount (number): Coupon discount amount
  - walletUsed (number): Amount paid from wallet
  - deliveryFee (number): Delivery charges
  - finalPayable (number): Final amount to pay
  - totalOrderAmount (number): Total order value

currency (string):
  - Always "INR" for Indian Rupees

paymentMode (string):
  - "cod" = Cash on Delivery
  - "razorpay" = Online payment via Razorpay
  - "wallet" = Full payment from wallet
  - "partial_wallet" = Partial wallet + other payment

deliveryAddress (Object):
  - id (string): Address ID
  - name (string): Recipient name
  - phoneNumber (string): Contact number
  - street (string): Combined line1 + line2
  - city (string): City name
  - state (string): State name
  - postalCode (string): PIN code
  - country (string): Country name
  - isDefault (boolean): Is default address
  - landmark (string, optional): Nearby landmark
  - email (string, optional): Email address

couponCode (string, nullable):
  - Coupon code if applied
  - null if no coupon used

WHAT FIREBASE FUNCTION DOES WITH THIS DATA
-------------------------------------------

The Firebase function receives this data and creates 3 documents:

1. orders/{orderId}
   - Stores: orderId, userId, status, items (with selectedColor), pricing, timestamps
   - selectedColor is saved in each item

2. payments/{paymentId}
   - Stores: paymentId, orderId, method, status, amount, attempts

3. deliveries/{deliveryId}
   - Stores: deliveryId, orderId, address, tracking, timestamps

KEY POINTS
----------

✅ selectedColor is OPTIONAL in items array
✅ Only included if user selected a color
✅ Sent exactly as user selected it ("Red", "Blue", etc.)
✅ Firebase function preserves it in the order
✅ Available in order history for display
✅ Can be used for order fulfillment

TESTING
-------

To verify selectedColor is being sent:

1. Add product with colors to cart
2. Select a color (e.g., "Red")
3. Proceed to checkout
4. Check Flutter console logs:
   - Look for: "Color: Red" in _prepareOrderItems logs
   - Look for: items array in Firebase function call logs

5. Check Firebase Function logs:
   - Go to Firebase Console → Functions → Logs
   - Find createOrder function execution
   - Check request.data.items[0].selectedColor

6. Check Firestore:
   - Go to orders collection
   - Open the created order
   - Check items[0].selectedColor field
