DATA FLOW
---------

1. User views product details page
2. If colors exist, color selector appears
3. User selects a color (e.g., "Red")
4. selectedColor is tracked in controller

5. User clicks "Add to Cart"
6. selectedColor is passed to cart service
7. Cart item is saved to Firestore with selectedColor field

8. User proceeds to checkout
9. Cart items are converted to order items
10. selectedColor is transferred to order item
11. Items with selectedColor are sent to Firebase createOrder function
12. Order is created in Firestore with selectedColor in each item
